# Plugins (`lennysh.traefik`)

This directory follows the [Ansible collection layout](https://docs.ansible.com/ansible/latest/dev_guide/developing_collections_structure.html#plugins-directory) for optional plugins (modules, filters, lookups, and so on).

**This collection does not ship any custom plugins yet.** The tree is reserved for future content; if you add a plugin, place it under the subdirectory that matches its type (for example `modules/`, `filter/`, `lookup/`).

General reference: [Working with plugins](https://docs.ansible.com/ansible/latest/plugins/plugins.html).
